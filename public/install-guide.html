이 도구가 하는 일

📊
업무 패턴 분석반복되거나 손이 많이 가는 작업을 찾아 개선점을 제안합니다
🤝
자동화 도우미단순·반복 작업을 줄여 더 중요한 일에 집중하도록 돕습니다
🔒
개인정보 보호업무 활동만 다루며, 개인 화면은 본인만 열람합니다(관리자는 팀 단위 집계만)

설치 방법

  1. 위 설치 시작 버튼 → 네노바-업무도구.bat 다운로드
  2. 다운로드한 파일 실행 → 관리자 권한 창에서 "예" 클릭
  3. 본인 이름 입력 (계정이 자동으로 연결됩니다)
  4. 설치가 끝나면 창을 닫으면 완료
⚠️ 설치 중 SmartScreen/백신 경고가 뜨면 "추가 정보 → 실행" 또는 "허용"을 눌러주세요. 회사에서 승인한 업무 도구라 안전합니다.

자주 묻는 것

• 설치 후 아무 창도 안 떠요 — 정상입니다. 조용히 백그라운드에서 동작하며 업무에 방해되지 않습니다.

• 내 개인 사생활은요? — 업무 활동만 다룹니다. 개인 화면은 본인만 보고, 관리자에게는 팀 단위 집계만 전달됩니다.

• 이름을 잘못 입력했어요 — 설치 버튼을 다시 눌러 재실행하면 됩니다(덮어쓰기).

• 컴퓨터가 느려지나요? — 아니요. 가볍게 동작하도록 만들어졌습니다.
