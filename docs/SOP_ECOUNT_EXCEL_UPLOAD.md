# SOP — 이카운트 엑셀 일괄업로드 (자료올리기)

> 대상: 이카운트에 판매/구매/거래처 자료를 **건별 수기입력**하고 있는 담당자
> 효과: 건별 입력 → 엑셀로 모아 **한 번에 업로드** (X-ray 진단 기준 주 ~30분 절감 + 오타 감소)
> 작성: 2026-08-07 (회사 X-ray Top3-③) · 근거: 관찰데이터(설연주 화면) + ECOUNT 공식 가이드

---

## 언제 쓰나
- 같은 유형 자료를 **여러 건** 입력할 때 (판매입력, 구매입력, 거래처/품목 등록 등)
- 다른 곳(엑셀·카톡 정리본)에 이미 표로 있는 자료를 이카운트에 옮길 때
- ❌ 1~2건 단발 입력은 그냥 화면에서 직접 (일괄업로드가 더 느림)

## 두 가지 방법

### 방법 A — 웹자료올리기 (웹에서 바로, 권장)
1. 이카운트 웹 로그인 → 해당 입력 메뉴로 이동
   - 예: **[재고Ⅰ] → [기초등록] → [거래처등록]** → 화면 하단 **[웹자료올리기]** 버튼
   - 판매/구매 등 다른 입력 메뉴도 같은 위치(하단)에 웹자료올리기 버튼이 있음
2. **서식 다운로드** → 열려진 엑셀 서식의 컬럼 순서 그대로 데이터 붙여넣기
3. 파일 업로드 → 미리보기 확인 → 올리기

### 방법 B — 엑셀 자료올리기 애드인 (설치형)
1. **[Self-Customizing] → [다운로드] → [엑셀 자료올리기 기능]** 설치
2. 엑셀에서 애드인 실행 → **[자료입력하기] → [재고] → [판매입력]** 등 원하는 서식 선택
3. 서식에 데이터 입력 → 애드인의 **자료올리기** 실행

## ⚠️ 실수 방지 5계명
1. **거래처·품목은 '이름'이 아니라 '코드'로 매칭**된다 — 코드가 틀리면 다른 거래처로 들어감. 업로드 전 코드 목록을 다운받아 VLOOKUP으로 코드를 채울 것.
2. **날짜 형식**은 서식이 요구하는 형태(YYYY-MM-DD 또는 YYYYMMDD) 그대로. 엑셀이 날짜를 자동 변환하지 않게 텍스트 서식 주의.
3. **서식의 컬럼 순서·헤더를 바꾸지 말 것** — 열 추가/삭제 금지, 값만 채운다.
4. 업로드 후 **반드시 합계 검증**: 이카운트 화면의 건수·금액 합계 ↔ 원본 엑셀 합계 대조. 다르면 실패행 확인.
5. **실패행이 있으면 그 행만 수정해 재업로드** — 전체 재업로드하면 중복 등록됨.

## 우리 회사 적용 (관찰 기준)
- 카톡 발주 정리본·주간 물량표를 이카운트에 옮길 때 이 방법을 기본으로.
- 자료올리기 서식 엑셀은 공유 폴더에 **회사 표준 서식**으로 저장해두고 재사용 (매번 새로 받지 말 것).
- 막히면: 서식 안 열림 → 방법 A(웹)로 우회 / 코드 모름 → 기초등록에서 코드 목록 다운로드.
